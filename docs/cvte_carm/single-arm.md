# A3 单臂：6 关节＋夹爪

[首页](../../README.md) · [SDK 安装与接口](README.md)

已做过单臂关节与夹爪现场测试。这里的“6＋1”不是七轴机械臂；夹爪独立于 6 维关节位置。
本次目录整理后的代码只做离线复核，不把旧现场结果当作本版本的重新验收。

以下安装、编译和运行均在上位机完成，通过 WebSocket `10.42.0.101:8090` 访问 A3 控制器。部署位置与可开发功能见 [架构链路](README.md#上位机与控制器的架构链路)。

## 第一步：读取状态

按 SDK 页面安装、编译后运行：

```bash
./build-cvte-only/cvte_carm_check --model a3 --ip 10.42.0.101
```

正常应看到 `joint_count=6 valid=1 degraded=0`、`connected=1`，程序退出码为 0。
程序不调用 ready、伺服或运动。失败时先解决状态问题。

Python 可打印关节和末端位姿：

```bash
source .venv/bin/activate
python examples/cvte_carm/read_state.py --model a3 --ip 10.42.0.101
```

## 第二步：关节与夹爪演示

确保运动空间清空、原厂急停可用；示例从当前姿态逐个关节偏移并返回，不能用于绕障或任意姿态自动验收。

```bash
python examples/cvte_carm/joint_gripper_demo.py \
  --ip 10.42.0.101 --amplitude 0.15 --move-time 3
```

程序读取当前姿态、关节限位与真实设备状态，展示计划后要求回车确认；然后调用 ready，依次测试 6 个关节和夹爪。旧现场脚本采用过 0.35 rad，本说明从较小的 0.15 rad 开始。

| 参数 | 作用 |
|---|---|
| `--amplitude 0.15` | 单关节偏移，rad；代码中第 3 关节取负方向 |
| `--move-time 3` | 每段运动时间，秒 |
| `--gripper-open 0.04` | 夹爪开口目标，米；受设备限位校验 |
| `--gripper-torque 5` | 该版本夹爪命令的力／力矩限制参数，按设备手册校准 |
| `--skip-gripper` | 仅测试关节 |
| `--yes` | 跳过交互确认；只用于已做好现场检查的自动流程 |

输出包括每关节目标、实际反馈、返回原位误差和夹爪读数。`PASS` 表示脚本调用完成，不代替精度、负载或碰撞检测验收。
按 Ctrl+C 中止后，脚本尝试 `emergency_stop` 并断开，不自动返回原位或自动闭合夹爪。
SDK 同步调用可能延迟 Python 中断处理，紧急情况使用原厂急停。
脚本正常结束仅断开连接，不自动关闭伺服；是否卸载支撑、关闭伺服按厂商操作规程执行。

## 二次开发

一般顺序：连接 → 读取型号、状态、限位 → 操作者确认 → ready → 校验伺服与模式 → 小幅运动 → 读反馈 → 结束任务。
示例只支持已测的六关节 A3；D3 请使用双臂页面，不能只改 IP 后运行这个运动脚本。
