# PM01 附加适配器

[首页](../README.md)

PM01 的既有适配器保留在 `src/bridge/adapters/pm01`，本次发布重点是 G1、K2、CArm 单／双臂，未对 PM01 做新的真机验收。

真实 ROS2 后端需要已配置的 ROS2 环境、`rclcpp` 和本仓库 `third_party/interface_protocol` 消息包。
构建前 `source /opt/ros/<发行版>/setup.bash`，然后运行 `bash scripts/build_robot.sh pm01`。
CMake 会配置和构建消息包；未安装 ROS2 的主机不应选择此目标或 `all`。

参考配置：[`config/pm01.sample.yaml`](../config/pm01.sample.yaml)。主要 topic 为 `/hardware/joint_state`、`/hardware/imu_info`、`/motion/motion_state`、`/hardware/joint_command`；运行前与现场发布者核对。
