# PM01 附加适配器

[首页](../README.md) · [通用开发指南](development.md)

既有 ROS2 适配器需要 `rclcpp` 和 `third_party/interface_protocol` 消息包。

```bash
source /opt/ros/<发行版>/setup.bash
bash scripts/build_robot.sh pm01
```

配置见 [pm01.sample.yaml](../config/pm01.sample.yaml)。主要 topic 为 `/hardware/joint_state`、`/hardware/imu_info`、`/motion/motion_state`、`/hardware/joint_command`，运行前与发布者核对。
